第一種基本句型 NP(主語) + Be(是) + NP(補語)
第二種基本句型 NP + Be(很) + Adj(形容詞)
第三種基本句型 NP + Be(在) + Adv~p(表場所的副詞)
第四種基本句型 NP + Vi(不及物動詞become, etc) + Adj
第五種基本句型 NP + Vi(seem, etc) + Adj
第六種基本句型 NP + Vi + Adv(表狀態的副詞)
第七種基本句型 NP + Vt(及物動詞) + NP(受詞)
第八種基本句型 NP + Vt~d(雙賓動詞) + IO(間接受詞) + DO(直接受詞)
第九種基本句型 NP + Vt~e + NP1(受詞) + NP2(受詞補語)
第十種基本句型 NP + Vt~c + NP1 + NP2
　 　
　

NP的意義

 NP（名詞組）代表名詞或其他具有與名詞相同功能的詞。NP可能是名詞（John, Mary, boy, dog, etc.），可能是代名詞（you, he, they, us, etc.），也可能是帶有修飾語的名詞（the lunch, my girl friends, the woman in red dress, etc.）。
